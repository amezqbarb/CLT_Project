Theoretical expectations

The population consists of the equally likely values:

[ 1,2,3,4,5,6 ]

population_values <- 1:6
population_probabilities <- rep(1 / 6, 6)

population_mean <- 3.5
population_variance <- 35 / 12
population_sd <- sqrt(population_variance)

population_skewness <- 0
population_excess_kurtosis <- -1.2686

The population mean is 3.5, and the population standard deviation is approximately 1.708. Because the die distribution is symmetric around 3.5, its skewness is 0. Its excess kurtosis is negative because the population is flatter and has lighter tails than a normal distribution.

The theoretical standard error is:

\[ \operatorname{SE}(\overline{X}) = \frac{\sigma}{\sqrt{n}} = \frac{\sqrt{35/12}}{\sqrt{n}}. \]

Prediction for the Six-Sided Die

The six-sided die distribution is discrete and not normally shaped, so I predict that smaller sample sizes will still show some discrete patterns and may not look perfectly bell-shaped. As (n) increases, I expect the sampling distribution of the sample mean to become more symmetric and approximately normal. I also expect its standard error to become closer to (/).

Reproducible Simulation Setup

The last four digits of my student ID are 4160, so I use 4160 as the seed. This makes the simulation reproducible.

student_id <- 4160
reps <- 10000

broad_n_values <- c(
  1, 5, 10, 15, 20, 25, 30
)

die_generator <- function(n) {
  sample(
    population_values,
    size = n,
    replace = TRUE
  )
}

simulate_means <- function(n, reps = 10000) {
  replicate(
    reps,
    mean(die_generator(n))
  )
}

run_simulations <- function(n_values, reps = 10000) {
  
  results <- list()
  
  for (n in n_values) {
    
    cat("Running simulation for n =", n, "\n")
    
    results[[paste0("n_", n)]] <- simulate_means(
      n = n,
      reps = reps
    )
  }
  
  results
}

Here, (n) is the number of die rolls in one sample. The value reps is the number of repeated samples used to create the sampling distribution.

convert_to_long_format <- function(
  means_list,
  n_values,
  range_label
) {
  
  do.call(
    rbind,
    lapply(seq_along(n_values), function(i) {
      
      data.frame(
        range = range_label,
        sample_size_n = n_values[i],
        repetition = seq_len(length(means_list[[i]])),
        sample_mean = means_list[[i]]
      )

  )

Diagnostic Functions

calculate_skewness <- function(x) {
  mean((x - mean(x))^3) / sd(x)^3
}

calculate_excess_kurtosis <- function(x) {
  mean((x - mean(x))^4) / sd(x)^4 - 3
}

calculate_outliers <- function(x) {
  
  q1 <- quantile(x, 0.25)
  q3 <- quantile(x, 0.75)
  iqr_value <- q3 - q1
  
  sum(
    x < q1 - 1.5 * iqr_value |
      x > q3 + 1.5 * iqr_value
  )
}

calculate_diagnostics <- function(
  means_list,
  n_values
) {
  
  simulated_means <- sapply(
    means_list,
    mean
  )
  
  simulated_se <- sapply(
    means_list,
    sd
  )
  
  theoretical_se <- population_sd / sqrt(n_values)
  
  tail_proportions <- sapply(
    seq_along(n_values),
    function(i) {
      
      mean(
        abs(
          means_list[[i]] - population_mean
        ) >
          3 * theoretical_se[i]
      )
    }
  )
  
  data.frame(
    sample_size_n = n_values,
    
    simulated_mean = simulated_means,
    
    theoretical_mean =
      rep(population_mean, length(n_values)),
    
    mean_error =
      simulated_means - population_mean,
    
    simulated_standard_error =
      simulated_se,
    
    theoretical_standard_error =
      theoretical_se,
    
    relative_standard_error_error =
      abs(
        simulated_se -
          theoretical_se
      ) / theoretical_se,
    
    skewness = sapply(
      means_list,
      calculate_skewness
    ),
    
    excess_kurtosis = sapply(
      means_list,
      calculate_excess_kurtosis
    ),
    
    outlier_count = sapply(
      means_list,
      calculate_outliers
    ),
    
    proportion_beyond_three_SE =
      tail_proportions
  )
}

Comparing Refined Sample Sizes

The following calculations compare the refined sample sizes using mean error, standard-error error, and Q–Q plot straightness.

qq_correlations <- c()

for (i in 1:length(refined_n_values)) {
  
  n <- refined_n_values[i]
  
  means <- refined_means[[paste0("n_", n)]]
  
  probabilities <- (
    (1:length(means)) - 0.5

    probabilities
  )

    sort(means),
    theoretical_quantiles

Selected Sample Size

For the Six-Sided Die Population, I selected (n = 14) as the smallest sample size that appeared normal enough.

For the broad investigation, I examined (n = 1, 5, 10, 15, 20, 25,) and (30). I compared the histograms, normal Q–Q plots, skewness, kurtosis, simulated standard errors, and tail behavior for these sample sizes.

The broad results suggested that (n = 10) was not quite normal enough, while (n = 20) appeared sufficiently close to normal. Therefore, I used (n = 10) and (n = 20) as the refinement bounds. I then tested every integer sample size from (n = 10) through (n = 20).

Among the refined sample sizes, (n = 14) was the smallest value that looked normal enough. Its histogram was centered close to the theoretical mean of (3.5) and had an overall bell-shaped pattern. Because the die is discrete, the histogram still contained some small spikes. These spikes are expected because sample means can only take certain discrete values, but the overall shape at (n = 14) was approximately normal.

The normal Q–Q plot for (n = 14) was approximately linear, although it was not perfectly straight. This supported the conclusion from the histogram that the sampling distribution was reasonably close to normal.

The skewness at (n = 14) was reasonably close to zero, which suggests that the sampling distribution was fairly symmetric. The excess kurtosis was also closer to zero than it was for smaller sample sizes, indicating that the shape was becoming more similar to a normal distribution.

The simulated standard error was close to the theoretical standard error:

\[ \operatorname{SE}(\overline{X}) = \frac{\sqrt{35/12}}{\sqrt{14}} \]

The simulated mean was also close to the theoretical population mean of (3.5). There was no major outlier or tail behavior that changed my decision. Any small differences in the tails were expected because the simulation was based on a discrete die population.

The numerical comparison score also supported this conclusion. It compared the absolute mean error, the absolute standard-error error, and the straightness of the Q–Q plot. Although the score was only supporting evidence, it identified (n = 14) as the best overall refined sample size. Therefore, I selected (n = 14) as the smallest sample size that appeared normal enough for this project.

CLT Assumptions and Limitations

The die rolls are independent and identically distributed, and the population has a finite mean and finite variance. Therefore, the usual Central Limit Theorem applies.

However, the original population is discrete and flat rather than bell-shaped. Because of this, the sampling distributions may still show small spikes even when their overall shape is approximately normal. The CLT describes the overall behavior of the sampling distribution, so these small spikes do not automatically mean that the distribution is not normal enough.

The definition of “normal enough” is also somewhat subjective. It depends on the histogram, Q–Q plot, numerical diagnostics, and how closely the simulated results match the theoretical values. Different reasonable criteria could lead to slightly different choices of (n).

Conclusion

For the Six-Sided Die Population, I selected (n = 14) as the smallest sample size that appeared normal enough.

The original die population is discrete and flat, but the sampling distribution of the mean became more symmetric and approximately bell-shaped as (n) increased. I narrowed the refinement range to (n = 10) through (n = 20), then tested every integer value in that interval.

At (n = 14), the histogram was approximately bell-shaped and centered near the theoretical mean of (3.5). The normal Q–Q plot was reasonably close to a straight line. The simulated mean was close to (3.5), and the simulated standard error was close to the theoretical value. Skewness was close to zero, excess kurtosis was closer to zero than it was for smaller values of (n), and no serious outlier or tail behavior affected the decision.

The numerical score agreed with the visual evidence and identified (n = 14) as the best overall refined sample size. Therefore, (n = 14) was my evidence-based choice for when the Six-Sided Die sampling distribution became normal enough.
