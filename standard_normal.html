Theoretical Expectations

The population follows:

\[ X \sim \mathcal{N}(0,1) \]

population_mean <- 0
population_variance <- 1
population_sd <- 1
population_skewness <- 0
population_excess_kurtosis <- 0

The population mean is 0 and the population standard deviation is 1. Because this is a Standard Normal population, its skewness and excess kurtosis are both 0.

The theoretical standard error is:

\[ \operatorname{SE}(\overline{X}) = \frac{\sigma}{\sqrt{n}} = \frac{1}{\sqrt{n}}. \]

Prediction for Standard Normal

Because the population is already normally distributed, I predict that the sampling distribution of the sample mean will be approximately normal for every sample size (n), including (n=1). Increasing (n) should reduce the standard error, but it should not be necessary to create normality.

Reproducible Simulation Setup

The last four digits of my student ID are 4160, so I use 4160 as the seed. This makes my simulation reproducible.

student_id <- 4160
reps <- 10000

broad_n_values <- c(
  1, 5, 10, 20, 30, 50, 75, 100
)

population_generator <- function(n) {
  rnorm(
    n,
    mean = population_mean,
    sd = population_sd
  )
}

simulate_means <- function(n, reps = 10000) {
  replicate(
    reps,
    mean(population_generator(n))
  )
}

run_simulations <- function(n_values, reps = 10000) {
  
  results <- list()
  
  for (n in n_values) {
    
    cat("Running simulation for n =", n, "\n")
    
    results[[paste0("n_", n)]] <- simulate_means(
      n = n,
      reps = reps
    )
  }
  
  results
}

Here, (n) is the number of Standard Normal observations in one sample. The value reps is the number of repeated samples used to create the sampling distribution.

convert_to_long_format <- function(
  means_list,
  n_values,
  range_label
) {
  
  do.call(
    rbind,
    lapply(seq_along(n_values), function(i) {
      
      data.frame(
        range = range_label,
        sample_size_n = n_values[i],

Diagnostic Functions

calculate_skewness <- function(x) {
  mean((x - mean(x))^3) / sd(x)^3
}

calculate_excess_kurtosis <- function(x) {
  mean((x - mean(x))^4) / sd(x)^4 - 3
}

calculate_outliers <- function(x) {
  
  q1 <- quantile(x, 0.25)
  q3 <- quantile(x, 0.75)
  iqr_value <- q3 - q1
  
  sum(
    x < q1 - 1.5 * iqr_value |
      x > q3 + 1.5 * iqr_value
  )
}

calculate_diagnostics <- function(
  means_list,
  n_values
) {
  
  simulated_means <- sapply(
    means_list,
    mean
  )
  
  simulated_se <- sapply(
    means_list,
    sd
  )
  
  theoretical_se <- population_sd / sqrt(n_values)
  
  tail_proportions <- sapply(
    seq_along(n_values),
    function(i) {
      
      mean(
        abs(
          means_list[[i]] - population_mean
        ) >
          3 * theoretical_se[i]
      )
    }
  )
  
  data.frame(
    sample_size_n = n_values,
    
    simulated_mean = simulated_means,
    
    theoretical_mean =
      rep(population_mean, length(n_values)),
    
    mean_error =
      simulated_means - population_mean,
    
    simulated_standard_error =
      simulated_se,
    
    theoretical_standard_error =
      theoretical_se,
    
    relative_standard_error_error =
      abs(
        simulated_se -
          theoretical_se
      ) / theoretical_se,
    
    skewness = sapply(
      means_list,
      calculate_skewness
    ),
    
    excess_kurtosis = sapply(
      means_list,
      calculate_excess_kurtosis
    ),
    
    outlier_count = sapply(
      means_list,
      calculate_outliers
    ),
    
    proportion_beyond_three_SE =
      tail_proportions
  )
}

for (i in 1:length(refined_n_values)) {
  
  n <- refined_n_values[i]
  
  means <- refined_means[[paste0("n_", n)]]
  
  probabilities <- (
    (1:length(means)) - 0.5

Selected Sample Size

The selected sample size is (n=1). Since the original population is already normal, the sample mean is normally distributed for every sample size. Increasing (n) reduces the standard error, but it is not needed to create normality.

CLT Assumptions and Limitations

The observations are independent and identically distributed, and the Standard Normal population has a finite mean and finite variance. This is a favorable case because the original population is already normal. Therefore, this distribution does not show how the CLT handles a skewed or heavy-tailed population.

Conclusion

The Standard Normal population is normal for every sample size (n), including (n=1). The simulations, histograms, Q–Q plots, and diagnostic values should all support this theoretical result. The main effect of increasing (n) is that the sampling distribution becomes narrower because its standard error decreases according to (1/).
