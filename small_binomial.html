Theoretical Expectations

The population follows a Binomial distribution with 5 trials and success probability 0.10:

\[ X \sim \operatorname{Binomial}(5, 0.10) \]

population_values <- 0:5
population_size <- 5
population_probability <- 0.10

population_probabilities <- dbinom(
  population_values,
  size = population_size,
  prob = population_probability
)

population_mean <-
  population_size * population_probability

population_variance <-
  population_size *
    population_probability *
    (1 - population_probability)

population_sd <- sqrt(population_variance)

population_skewness <-
  (1 - 2 * population_probability) /
    sqrt(
      population_size *
        population_probability *
        (1 - population_probability)
    )

population_excess_kurtosis <-
  (
    1 -
      6 *
        population_probability *
        (1 - population_probability)
  ) /
    (
      population_size *
        population_probability *
        (1 - population_probability)
    )

theoretical_values <- data.frame(
  mean = population_mean,
  variance = population_variance,
  standard_deviation = population_sd,
  skewness = population_skewness,
  excess_kurtosis = population_excess_kurtosis
)

The theoretical mean is:

\[ \mu = np = 5(0.10) = 0.5. \]

The theoretical variance is:

\[ \sigma^2 = np(1-p) = 5(0.10)(0.90) = 0.45. \]

The theoretical standard deviation is:

\[ \sigma = \sqrt{0.45}. \]

The population is right-skewed because the probability of success is small. Most observations are expected to be close to zero, while larger numbers of successes are less common.

The theoretical standard error is:

\[ \operatorname{SE}(\overline{X}) = \frac{\sigma}{\sqrt{n}} = \frac{\sqrt{0.45}}{\sqrt{n}}. \]

Prediction for the Small Binomial Population

The original Binomial population is discrete and right-skewed. I expect the sampling distribution of the mean to become more symmetric and approximately normal as \(n\) increases.

Because the success probability is only 0.10, most observations are zero. Therefore, I expect smaller sample sizes to show noticeable spikes and right-skewness. As \(n\) increases, the sample means should become smoother, more bell-shaped, and closer to the theoretical mean of 0.5.

student_id <- 4160
reps <- 10000

broad_n_values <- c(
  1, 5, 10, 20, 30, 50, 75, 100
)

binomial_generator <- function(n) {
  rbinom(
    n,
    size = population_size,
    prob = population_probability
  )
}

simulate_means <- function(n, reps = 10000) {
  replicate(
    reps,
    mean(binomial_generator(n))
  )
}

run_simulations <- function(n_values, reps = 10000) {
  
  results <- list()
  
  for (n in n_values) {
    
    cat("Running simulation for n =", n, "\n")
    
    results[[paste0("n_", n)]] <- simulate_means(
      n = n,
      reps = reps
    )
  }
  
  results
}

Here, \(n\) is the number of independent Binomial observations in one sample. The value reps is the number of repeated samples used to create each sampling distribution.

convert_to_long_format <- function(
  means_list,
  n_values,
  range_label
) {
  
  do.call(
    rbind,
    lapply(seq_along(n_values), function(i) {
      
      data.frame(
        range = range_label,
        sample_size_n = n_values[i],
        repetition = seq_len(
          length(means_list[[i]])
        ),
        sample_mean = means_list[[i]]
      )
    })
  )
}

Diagnostic Functions

calculate_skewness <- function(x) {
  
  mean((x - mean(x))^3) / sd(x)^3
}

calculate_excess_kurtosis <- function(x) {
  
  mean((x - mean(x))^4) / sd(x)^4 - 3
}

calculate_outliers <- function(x) {
  
  q1 <- quantile(x, 0.25)
  q3 <- quantile(x, 0.75)
  iqr_value <- q3 - q1
  
  sum(
    x < q1 - 1.5 * iqr_value |
      x > q3 + 1.5 * iqr_value
  )
}

calculate_diagnostics <- function(
  means_list,
  n_values
) {
  
  simulated_means <- sapply(
    means_list,
    mean
  )
  
  simulated_standard_errors <- sapply(
    means_list,
    sd
  )
  
  theoretical_standard_errors <-
    population_sd / sqrt(n_values)
  
  tail_proportions <- sapply(
    seq_along(n_values),
    function(i) {
      
      mean(
        abs(
          means_list[[i]] - population_mean
        ) >
          3 * theoretical_standard_errors[i]
      )
    }
  )
  
  results <- data.frame(
    sample_size_n = n_values,
    
    simulated_mean = simulated_means,
    
    theoretical_mean =
      rep(
        population_mean,
        length(n_values)
      ),
    
    mean_error =
      simulated_means - population_mean,
    
    simulated_standard_error =
      simulated_standard_errors,
    
    theoretical_standard_error =
      theoretical_standard_errors,
    
    relative_standard_error_error =
      abs(
        simulated_standard_errors -
          theoretical_standard_errors
      ) / theoretical_standard_errors,
    
    skewness = sapply(
      means_list,
      calculate_skewness
    ),
    
    excess_kurtosis = sapply(
      means_list,
      calculate_excess_kurtosis
    ),
    
    outlier_count = sapply(
      means_list,
      calculate_outliers
    ),
    
    proportion_beyond_three_theoretical_SE =
      tail_proportions
  )
  
  results
}

Comparing Refined Sample Sizes

The goal is to select the smallest sample size that appears normal enough. The numerical criteria support the visual evidence from the histograms and Q-Q plots.

qq_correlations <- c()

for (i in 1:length(refined_n_values)) {
  
  n <- refined_n_values[i]
  
  means <- refined_means[[paste0("n_", n)]]
  
  probabilities <- (
    (1:length(means)) - 0.5
  ) / length(means)
  
  theoretical_quantiles <- qnorm(
    probabilities
  )
  
  qq_correlations[i] <- cor(
    sort(means),
    theoretical_quantiles
  )
}

refined_diagnostics$absolute_mean_error <-
  abs(
    refined_diagnostics$mean_error
  )

refined_diagnostics$absolute_standard_error_error <-
  abs(
    refined_diagnostics$simulated_standard_error -
      refined_diagnostics$theoretical_standard_error
  )

refined_diagnostics$qq_correlation <-
  qq_correlations
refined_diagnostics$mean_error_rank <- rank(
  refined_diagnostics$absolute_mean_error,
  ties.method = "min"
)

refined_diagnostics$standard_error_rank <- rank(
  refined_diagnostics$absolute_standard_error_error,
  ties.method = "min"
)

refined_diagnostics$qq_rank <- rank(
  -refined_diagnostics$qq_correlation,
  ties.method = "min"
)

refined_diagnostics$total_score <-
  refined_diagnostics$mean_error_rank +
    refined_diagnostics$standard_error_rank +
    refined_diagnostics$qq_rank

Selected Sample Size

CLT Assumptions and Limitations

The Binomial observations are independent and identically distributed, and the population has a finite mean and finite variance. Therefore, the usual Central Limit Theorem applies.

The original Binomial population is discrete and right-skewed because the probability of success is only 0.10. As the sample size increases, averaging the observations makes the sampling distribution more symmetric and approximately normal.

The histograms may still show small spikes because the original observations can only take integer values. These spikes are expected from the discrete population and do not automatically mean that the sampling distribution is not normal enough.

The definition of “normal enough” is somewhat subjective. It depends on the histogram, Q-Q plot, numerical diagnostics, and how closely the simulated results match the theoretical values. Different reasonable criteria could lead to slightly different choices of \(n\).
